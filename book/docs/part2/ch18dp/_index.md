**2D 规划**

二维平面移动，值的更新只依赖「上方」和「左方」，可降为一维数组，滚动计算。**一定要掌握滚动数组**。

```go
// dp[j] 更新前是上方的值，dp[j-1] 是左方的值
dp[j] = dp[j] + dp[j-1]
```

在二维平面移动的基础之上，还有一类题目，值的更新依赖「上方」，「左方」和「左上角」三个邻居，也可降为一维数组，滚动计算，需额外增加 prev 变量记录「左上角」的值。

以编辑距离为例，普通二维递推的代码模板是：

```go
// 原始动规方程为
if word[i-1] == word[j-1]
	dp[i][j] = dp[i-1][j-1]
else
  dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

空间优化，压缩到一维滚动数组后，其模板是：

```go
func minDistance1D(word1 string, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([]int, n+1)
    for j := 0; j <= n; j++ { // 第 0 行：word1 为空，需插入 j 个字符
        dp[j] = j
    }

    for i := 1; i <= m; i++ {
        // prev 左上角,所以在每行开始时要初始化
        prev := dp[0] // dp[i-1][j-1]，初始为上一行第 0 列
        dp[0] = i     // 第 0 列：word2 为空，需删光 word1 前 i 个字符
        for j := 1; j <= n; j++ {
            // 更新前的 dp[j] = 上一行 dp[i-1][j]（上方值），先存下来
            // j 就是下一轮 j+1 的左上角，保存下来给 prev 赋值
            temp := dp[j] // 更新前的 dp[j] = 上一行 dp[i-1][j]（上方值），先存下来，
          
            if word1[i-1] == word2[j-1] {
                dp[j] = prev // 相等，直接继承左上角，无需操作
            } else {
                dp[j] = min(dp[j], dp[j-1], prev) + 1
                //         ↑        ↑          ↑
                //       上方      左方      左上方
                //  dp[j]    本行未覆盖 → 上一行 dp[i-1][j]
                //  dp[j-1]  本行已覆盖 → 本行   dp[i][j-1]
                //  prev     上一行左上 dp[i-1][j-1]
            }
            prev = temp // 本轮旧 dp[j] 成为下一列 (j+1) 的左上角
        }
    }
    return dp[n]
}
```
