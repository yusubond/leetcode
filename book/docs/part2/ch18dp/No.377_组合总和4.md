## 377 组合总和 Ⅳ-中等

题目：

给你一个由 **不同** 整数组成的数组 `nums`，和一个目标整数 `target`。请你从 `nums` 中找出并返回总和为 `target` 的元素组合的个数。

题目数据保证答案符合 32 位整数范围。



**关键观察**

虽然题目叫"组合总和"，但实际求的是**排列数**——不同顺序视为不同方案。

例如 `nums = [1,2,3]`, `target = 4`，答案为 7：
```
(1,1,1,1)  (1,1,2)  (1,2,1)  (1,3)
(2,1,1)    (2,2)    (3,1)
```
注意 `(1,1,2)`、`(1,2,1)`、`(2,1,1)` 被计为 3 种——这就是排列。



**DP 转移方程**

定义 `dp[i]` = 总和为 `i` 的排列个数。对每个 `num`，可以把它拼到结果为 `i - num` 的排列末尾：

```
dp[i] = Σ dp[i - num]   (对每个 num ≤ i)
dp[0] = 1                // 凑出 0 有一种：什么都不选
```

**决定成败的关键——循环顺序**：

```go
for i := 1; i <= target; i++ {     // 外层：金额
    for _, num := range nums {      // 内层：数字
        if i >= num {
            dp[i] += dp[i-num]
        }
    }
}
```

外层金额、内层数字 → **排列数**（本题要的）。因为对每个金额 `i`，依次尝试用各个数字作为"最后一个"，排列 `{1,2}` 和 `{2,1}` 会分别在不同轮次被计入。

这也是它与 [No.518 零钱兑换 2](../No.518_零钱兑换2/) 的本质区别——No.518 外 coin 内 amount，求组合数；本题反过来，求排列数。

```go
// date 2026/07/12
func combinationSum4(nums []int, target int) int {
    dp := make([]int, target+1)
    dp[0] = 1
    for i := 1; i <= target; i++ {
        for _, num := range nums {
            if i >= num {
                dp[i] += dp[i-num]
            }
        }
    }
    return dp[target]
}
```



**DP 过程示例**

`nums = [1,2,3]`, `target = 4`：

| i | 可用数字 | dp 更新过程 | dp[i] |
|---|---------|------------|-------|
| 0 | — | 初始化 | 1 |
| 1 | 1 | dp[1] += dp[0] | 1 |
| 2 | 1,2 | dp[2] += dp[1] + dp[0] | 2 |
| 3 | 1,2,3 | dp[3] += dp[2] + dp[1] + dp[0] | 4 |
| 4 | 1,2,3 | dp[4] += dp[3] + dp[2] + dp[1] | 7 |

**进阶**：如果 `nums` 中包含负数，且要求排列长度有限制，需要加维度限制步数，否则会出现无限长度的解。



**与相邻题的关系**

| 题目 | 求的是 | 循环顺序 | 计数方式 |
|------|--------|---------|---------|
| **No.377（本题）** | 排列数 | 外 amount 内 coin | `(1,2)` 和 `(2,1)` 各算一次 |
| No.518 零钱兑换 2 | 组合数 | 外 coin 内 amount | `(1,2)` 和 `(2,1)` 算同一种 |
| No.322 零钱兑换 | 最小值 | 任意顺序均可 | 不涉及计数，只比大小 |
| No.70 爬楼梯 | 排列数 | 本质是本题 `nums=[1,2]` 的特例 | `dp[i] = dp[i-1] + dp[i-2]` |

**一句话记忆**：求排列数 → 外层金额内层数字；求组合数 → 外层数字内层金额。

复杂度：时间复杂度 O(n × target)，空间复杂度 O(target)，其中 n 为 nums 长度。
