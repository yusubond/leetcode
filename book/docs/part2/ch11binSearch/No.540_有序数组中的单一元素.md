## 540 有序数组中的单一元素-中等

题目：

给你一个仅由整数组成的有序数组，其中每个元素都会出现两次，唯有一个数只会出现一次。

请你找出并返回只出现一次的那个数。

你设计的解决方案必须满足 `O(log n)` 时间复杂度和 `O(1)` 空间复杂度。

> **示例 1：**
>
> ```
> 输入：nums = [1,1,2,3,3,4,4]
> 输出：2
> ```
>
> **示例 2：**
>
> ```
> 输入：nums = [1,1,2]
> 输出：2
> ```

**关键观察：成对下标的奇偶性**

数组长度恒为奇数 `2k+1`。把下标按 `(偶, 奇)` 两两分组：`(0,1), (2,3), (4,5), …`。

- 在**单一元素之前**，每对都是“左偶 = 右奇”（如 `nums[0]==nums[1]`），配对完整。
- 单一元素必落在某个**偶数下标** `s`（它前面的数对共占偶数个位置）。一旦它插进来，之后的配对整体**右移一格**，变成 `(奇, 偶)`：`nums[s+1]==nums[s+2]`、`nums[s+3]==nums[s+4]`……
- 于是存在一条“单调”的分界：`mid < s` 时 `nums[mid]` 仍与它正常的配对邻居相等；`mid >= s` 时配对被打乱。**每次比较都能判定单一元素在中点左侧还是右侧**，从而二分。

**解法 1：异或配对二分（推荐）**

`mid^1` 会翻转最低位：`mid` 为偶时得 `mid+1`、为奇时得 `mid-1`，正好指向 `mid` “本应配对”的那个邻居。

- 若 `nums[mid] == nums[mid^1]`：配对完整 → `mid` 落在单一元素**左侧**，向右收缩 `left = mid+1`。
- 否则：配对被打乱 → 单一元素在 `mid` 或更左，向左收缩 `right = mid`。

```go
// date 2023/12/05
func singleNonDuplicate(nums []int) int {
    n := len(nums)

    // find the first index x that nums[x] != nums[x^1]
    left, right := 0, n-1
    for left < right {
        mid := (right - left) / 2 + left
        // 只要和相邻的元素相等，那么 x 一定在右边
        // left = mid + 1, 向右收缩
        if nums[mid] == nums[mid^1] {
            left = mid+1
        } else {
            right = mid
        }
    }
    return nums[left]
}
```

**解法 2：偶数对齐后比较下一项**

不用异或，直接把 `mid` 对齐到偶数（作为一对的左端），再比较 `nums[mid]` 与 `nums[mid+1]`：

- 相等 → 这对完整 → 单一元素在 `mid+2` 及以右，`left = mid+2`。
- 不等 → 配对已乱 → 单一元素在 `mid` 或左侧，`right = mid`。

```go
// date 2026/06/29
func singleNonDuplicate(nums []int) int {
    left, right := 0, len(nums)-1
    for left < right {
        mid := left + (right-left)/2
        if mid%2 == 1 {
            mid-- // 对齐到偶数下标，作为一对的左端
        }
        if nums[mid] == nums[mid+1] {
            left = mid + 2 // 这对完整，单一元素在右半
        } else {
            right = mid // 配对被打乱，单一元素在 mid 或左半
        }
    }
    return nums[left]
}
```

**复杂度**

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 解法1 异或配对 `mid^1` | O(log n) | O(1) | 一行条件覆盖奇偶两种情况，最简洁 |
| 解法2 偶数对齐比较 | O(log n) | O(1) | 不依赖位运算技巧，配对语义更直观 |

> 两解法同构（都按“配对是否完整”划分区间），渐近一致；解法1 用 `mid^1` 把奇偶判断压缩进一行，写法更短。
