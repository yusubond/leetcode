## 240 搜索二维矩阵-中等

题目：

编写一个高效的算法来搜索 `*m* x *n*` 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

> **示例 1：**
>
> ```
> 输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
> 输出：true
> ```
>
> **示例 2：**
>
> ```
> 输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
> 输出：false
> ```

**关键观察（与 LC 74 的根本区别）**

240 只保证“行升序、列升序”，但**行首不一定大于上一行行尾**（例如 `[[1,4],[2,5]]` 中第二行首元素 `2` 小于第一行末元素 `4`）。因此整张矩阵**不能展平成一维有序数组**，无法像 [No.074](./No.074_搜索二维矩阵.md) 那样直接二分；必须利用“行列双有序”这一结构。

**解法 1：Z 字查找（右上角出发，最优）**

因为矩阵行升序、列升序，可以以右上角的元素为基准。

如果右上角元素大于目标值，那么这一列不会有答案；

如果右上角元素小于目标值，那么这一行不会有答案；

每一步排除一行或一列，共 m+n 步内完成。`O(m+n)` 已是该矩阵结构下的渐近下界（adversary 论证：最坏情况必须检查 Ω(m+n) 个元素），故无法从渐近意义上超越。

```go
// date 2023/12/05
func searchMatrix(matrix [][]int, target int) bool {
    m := len(matrix)
    n := len(matrix[0])
    // Z 字查找
    x, y := 0, n-1
    for x < m && y >= 0 {
        if matrix[x][y] == target {
            return true
        } else if matrix[x][y] > target {  // 说明这一列不可能有
            y--
        } else { // 说明这一行不可能存在答案
            x++
        }
    }
    return false
}
```

**解法 2：逐行二分（备选，可剪枝）**

每一行本身就是有序的，可逐行二分；进入二分前用行首/行尾做区间剪枝，跳过 target 必不在的行。

```go
// date 2026/06/29
func searchMatrix(matrix [][]int, target int) bool {
    n := len(matrix[0])
    for _, row := range matrix {
        // 剪枝：target 不在 [row[0], row[n-1]] 区间，跳过该行
        if target < row[0] || target > row[n-1] {
            continue
        }
        lo, hi := 0, n-1
        for lo <= hi {
            mid := lo + (hi-lo)/2
            if row[mid] == target {
                return true
            } else if row[mid] < target {
                lo = mid + 1
            } else {
                hi = mid - 1
            }
        }
    }
    return false
}
```

- 进一步可对较短的一边二分，达到 `O(min(m,n) · log(max(m,n)))`。
- **何时更优**：当矩阵“瘦高”（m 很小、n 很大）时，`m·log n` 可能小于 Z 字的 `m+n`；一般情形 Z 字更稳。

**复杂度**

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 解法1 Z 字查找（右上角） | O(m+n) | O(1) | 渐近最优，已是下界 |
| 解法2 逐行二分（带剪枝） | O(m log n) | O(1) | 瘦高矩阵可能更快，可按行首尾剪枝 |

> ❌ **不可展平二分**：240 非全局有序，展平后不是有序数组，二分会出错。这正是它能用 Z 字、却不能用 74 那种一维二分的原因。
