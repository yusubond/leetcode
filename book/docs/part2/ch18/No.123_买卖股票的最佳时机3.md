## 123 买卖股票的最佳时机3

题目：

给定一个数组 prices，它的第 i 个元素是一支给定股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 两笔 交易。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。



分析：

最多 2 笔交易，每笔都是"先买后卖"。把交易进度拆成 4 个状态，用 4 个变量记录到达每个状态时的最大累计利润，一天一天往后推：

- buy1：第 1 次买入后的最大利润（持仓，利润为负的买入价）
- sell1：第 1 次卖出后的最大利润（第 1 笔完成）
- buy2：第 2 次买入后的最大利润（含第 1 笔收益）
- sell2：第 2 次卖出后的最大利润（第 2 笔完成）

对每一天价格 p，每个状态都取"维持原状 vs 今天操作"的较大值：

- `buy1 = max(buy1, -p)`：第 1 次买，选最低买入价
- `sell1 = max(sell1, buy1 + p)`：第 1 次卖
- `buy2 = max(buy2, sell1 - p)`：第 2 次买，带着第 1 笔收益去买
- `sell2 = max(sell2, buy2 + p)`：第 2 次卖，即最终答案

初始化用第 0 天：`buy1 = buy2 = -prices[0]`，`sell1 = sell2 = 0`。答案是 `sell2`（它也覆盖了只做 1 笔或 0 笔的情况）。同一天先买后卖净利润为 0，所以顺序更新是安全的。



```go
// date 2026/06/20
func maxProfit(prices []int) int {
    buy1, sell1 := -prices[0], 0
    buy2, sell2 := -prices[0], 0
    for i := 1; i < len(prices); i++ {
        p := prices[i]
        buy1 = max(buy1, -p)          // 第一次买入后的最大利润
        sell1 = max(sell1, buy1+p)    // 第一次卖出后的最大利润
        buy2 = max(buy2, sell1-p)     // 第二次买入（含第一笔收益）
        sell2 = max(sell2, buy2+p)    // 第二次卖出，即最终答案
    }
    return sell2
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

以 `prices = [3,3,5,0,0,3,1,4]` 为例，最优为两笔：0 买 3 卖、1 买 4 卖，各赚 3，共 **6**。

**复杂度分析**

- 时间复杂度 O(n)，一趟遍历
- 空间复杂度 O(1)，只用 4 个变量

> 推广到最多 k 笔交易就是 188 题，状态变成 `buy[j]` / `sell[j]`（j = 1..k）。本题 k = 2，直接展开成 4 个标量最快。
