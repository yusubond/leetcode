## 179 最大数-中等

给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。

**注意：**输出结果可能非常大，所以你需要返回一个字符串而不是整数。

> **示例 1：**
>
> ```
> 输入：nums = [10,2]
> 输出："210"
> ```
>
> **示例 2：**
>
> ```
> 输入：nums = [3,30,34,5,9]
> 输出："9534330"
> ```

**解题思路**

核心是**自定义排序**。两个数 `a`、`b` 谁该排前面，取决于拼接后哪个更大：若 `a+b > b+a`（字符串拼接），则 `a` 排在 `b` 前。排完序后依次拼接即可。

- 不能直接按字典序排序：`"3"` 与 `"30"` 拼接时 `"330" > "303"`，故 `3` 应在 `30` 前；而字典序 `"3" < "30"` 会得到错误顺序。
- **全零边界**：若排序后首位仍是 `'0'`，说明所有数都是 `0`，直接返回 `"0"`，避免出现 `"000..."`。

**为什么这个排序规则可用（传递性）**

把拼接视为数值：`a+b = a·10^len(b) + b`。比较 `a+b` 与 `b+a` 等价于比较

```
a / (10^len(a) - 1)   与   b / (10^len(b) - 1)
```

即把每个数看作“无限循环小数”形式的有理数（如 `3` ↔ `0.333…`，`30` ↔ `0.3030…`），再比较这些有理数的大小。有理数比较是全序关系，天然满足传递性，因此可放心交给排序使用。

**解法 1：自定义排序（首字符优化）**

当两个字符串首字符不同时，最高位就已分出胜负，字典序比较与拼接比较等价，可直接比较避免拼接；首字符相同时才拼接比较。

```go
// date 2026.06.21
func largestNumber(nums []int) string {
	str := make([]string, len(nums))
	for i, v := range nums {
		str[i] = strconv.Itoa(v)
	}

	// sort num 符合字母表排序
	sort.Slice(str, func(i, j int) bool {
		if str[i][0] == str[j][0] {
			return str[i]+str[j] > str[j]+str[i]
		}
		return str[i] > str[j]
	})

	ans := strings.Join(str, "")
	if ans[0] == '0' {
		return "0"
	}
	return ans
}
```

**解法 2：自定义排序（标准拼接写法）**

每次比较都直接拼接，写法最简洁，是通用模板。

```go
// date 2026/06/29
func largestNumber(nums []int) string {
	strs := make([]string, len(nums))
	for i, v := range nums {
		strs[i] = strconv.Itoa(v)
	}

	sort.Slice(strs, func(i, j int) bool {
		return strs[i]+strs[j] > strs[j]+strs[i]
	})

	// 首元素为 "0" 说明所有数都是 0，直接返回 "0"
	if strs[0] == "0" {
		return "0"
	}
	return strings.Join(strs, "")
}
```

**复杂度**

设 `n` 为元素个数，`k` 为最大位数（`nums[i] ≤ 10^9`，故 `k ≤ 10`）。

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 解法1 首字符优化 | O(n log n · k) | O(n·k) | 首字符不同时跳过拼接，常数更优 |
| 解法2 标准拼接 | O(n log n · k) | O(n·k) | 写法简洁，每次比较都拼接 |
