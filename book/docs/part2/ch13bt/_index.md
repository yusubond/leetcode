## 回溯算法

回溯算法和二叉树的 DFS 类似，本质上是一种暴力穷举算法。

抽象地说，解决一个回溯问题，实际上就是遍历一颗决策树的过程，树的每个叶子节点存放着一个合法答案。

我们把整棵树遍历一遍，把叶子节点上的答案全部收集起来，就能得到所有的合法答案。



站在回溯决策树的一个节点上，你只需要思考三个问题：

1. 路径：那些已经做出的选择
2. 选择列表：就是你当前可以做的选择
3. 结束条件：到达决策树的底层，无法再做选择的条件



代码方面，回溯算法的基本框架是：

```go
func backtrack(选择列表, 路径) {
  if 满足结束条件 {
    result.add(路径)
    return
  }
  for 选择 := range 选择列表 {
    做出选择（将选择加入路径）
    backtrace(路径, 选择列表) // 进入下一层决策
    撤销选择（将选择从路径移除） // <- 这就是"回溯"
  }
}
```

第二类：子集问题

**子集概念**

从集合 A 中选取部分元素组成一个小集合 B，小集合 B 视为集合 A 的子集。

两个特殊子集，空集合和自身。

因为子集问题更像是探索空间，没有明确的结束条件，而是记录全量路径，所以回溯算法框架要适当变化。

```go
func backtrack(选择列表，路径) {
  // 为的就是记录全量路径，所以上来就加
  result.add(路径)
  for 选择 := range 选择列表 {
    // 可做剪枝
    做出选择（将选择加入路径）
    backtrace(选择列表, 路径) // 进入下一层决策
    撤销选择（将选择从路径移除） // <- 这就是"回溯"
  }
}
```
