## 45 跳跃游戏2-中等

题目：

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。换句话说，如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处:

- `0 <= j <= nums[i]` 
- `i + j < n`

返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

> **示例 1:**
>
> ```
> 输入: nums = [2,3,1,1,4]
> 输出: 2
> 解释: 跳到最后一个位置的最小跳跃数是 2。
>      从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。
> ```
>
> **示例 2:**
>
> ```
> 输入: nums = [2,3,0,1,4]
> 输出: 2
> ```

**关键观察：按“跳跃层”分层（BFS 思想）**

把每个下标按“到达它所需的最少跳跃数”分层：

- 第 0 层 = `{0}`（起点，0 跳）。
- 第 `k+1` 层 = 从第 `k` 层任意一点**一步**能到达、且尚未被更早层覆盖的下标。

这些层在数轴上恰好是**一段段连续区间**。于是只需维护：

- `end` —— 当前这一跳（第 `k` 跳）能覆盖到的右边界；
- `maxPos` —— 在当前层内遍历时，所有点能进一步触及的**最远位置**（即下一层的右边界候选）。

当遍历指针 `i` 越过 `end`，说明进入了下一层：跳跃数 `+1`，并把 `end` 更新为 `maxPos`。这等价于“在当前一跳覆盖范围内，选使 `i+nums[i]` 最大的点继续”，故为贪心，一轮遍历 `O(n)`。

**解法 1：分层贪心（推荐，O(n)）**

```go
// date 2024/02/20
func jump(nums []int) int {
    // size 是最后要到达的位置
    size := len(nums)-1
    // ans 跳跃的步数
    // maxPos 表示从当前位置出发可跳跃的最远距离
    // end 记录跳跃的边界
    ans, end, maxPos := 0, 0, 0

    // i < size, 即不访问最后那个位置元素
    // 因为题目中已经说明一定可以到达最后的位置，所以如果 end == n-1，那么就会记录一次不必要的跳跃
    for i := 0; i < size; i++ {
        // 更新最远跳跃距离
        if i + nums[i] > maxPos {
            maxPos = i + nums[i]
        }
        // 到达边界，那么一定要跳了
        // 更新边界，并跳跃次数增加1
        if i == end {
            end = maxPos
            ans++
        }
    }

    return ans
}
```

> 为何循环到 `size-1`（不到末尾）：末尾是**终点**而非起跳点，到达它即结束；若把它也算作一层，会多记一跳。

**解法 2：动态规划（O(n²)，作对照）**

令 `dp[i]` 为到达下标 `i` 的最少跳跃数。对每个 `i`，用它可更新其后 `[i+1, i+nums[i]]` 内所有点：`dp[j] = min(dp[j], dp[i]+1)`。

```go
// date 2026/06/29
// 解法2 动态规划
func jump(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    for i := 1; i < n; i++ {
        dp[i] = n // 用 n 作“不可达”哨兵（最少跳跃数 < n）
    }
    for i := 0; i < n; i++ {
        for j := i + 1; j <= i+nums[i] && j < n; j++ {
            if dp[i]+1 < dp[j] {
                dp[j] = dp[i] + 1
            }
        }
    }
    return dp[n-1]
}
```

**复杂度**

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 解法1 分层贪心 | O(n) | O(1) | 一轮遍历，按跳跃层推进，最优 |
| 解法2 动态规划 | O(n²) | O(n) | 逐点松弛，思路直接但常数与空间更大 |

> 本题保证可达末尾，故无需判断不可达；若题目改为“可能不可达”，贪心解法需在 `maxPos <= i` 时提前返回 `-1`（参考 [No.55](./No.55_跳跃游戏.md) 的可达性判断）。
