## 55 跳跃游戏-中等

题目：

给你一个非负整数数组 `nums` ，你最初位于数组的 **第一个下标** 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true` ；否则，返回 `false` 。

> **示例 1：**
>
> ```
> 输入：nums = [2,3,1,1,4]
> 输出：true
> 解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
> ```
>
> **示例 2：**
>
> ```
> 输入：nums = [3,2,1,0,4]
> 输出：false
> 解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。
> ```

**关键观察：维护“最远可达位置”**

从下标 `i` 出发，能落到 `[i+1, i+nums[i]]` 中的任意一点；这些点又都是新的起跳点。于是只要记录当前能到达的**最远位置** `maxReach`：

- 遍历到 `i` 时，若 `i > maxReach`，说明 `i` 本身都到不了，更到不了末尾 → 返回 `false`。
- 否则用 `i + nums[i]` 更新 `maxReach`。
- 能把整个数组遍历完，就说明末尾可达。

核心是**只关心“最远能到哪”，不关心具体怎么跳**——这正是贪心优于搜索/DP 的地方。

**解法 1：正向贪心（推荐）**

```go
// date 2024/02/20
// 解法1 贪心算法
func canJump(nums []int) bool {
	maxStep := 0
	for i, v := range nums {
    // i 当前所在位置
    // 当当前位置超过最大跳跃距离时，则无法到达尾部
		if i > maxStep {
			return false
		}
		// i + nums[i] 就是能够到达的最远距离
		maxStep = max(maxStep, i+v)
	}
	return true
}
```

**解法 2：反向贪心（从右往左收缩目标）**

把“能否从 0 到 `n-1`”反过来想：令 `target = n-1`，从右往左扫，只要 `i + nums[i] >= target`，就说明从 `i` 能到当前目标，于是把目标收缩到 `i`；最终 `target` 能一路收到 `0` 即可达。

```go
// date 2026/06/29
// 解法2 反向贪心：从右往左收缩目标
func canJump(nums []int) bool {
	target := len(nums) - 1
	for i := len(nums) - 2; i >= 0; i-- {
		if i+nums[i] >= target {
			target = i // 从 i 能到当前目标，把目标收缩到 i
		}
	}
	return target == 0
}
```

**复杂度**

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 解法1 正向贪心（最远可达） | O(n) | O(1) | 一次遍历，遇到不可达可提前返回 |
| 解法2 反向贪心（收缩目标） | O(n) | O(1) | 从末尾反推起点，逻辑对称、易理解 |

> DP 也可解：令 `dp[i]` 表示下标 `i` 是否可达，`dp[i] = ∃ j<i, dp[j] && j+nums[j]≥i`，时间 `O(n²)`。但本题只判断可达性，贪心 `O(n)` 足矣，DP 属大材小用。
