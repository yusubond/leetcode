## 第 21 章 图 Graph

### 1、基本概念

图（Graph）由顶点（Vertex）和边（Edge）组成，记为 `G = (V, E)`。相比线性表（一对一）和树（一对多），图表示的是**多对多**的关系，是数据结构中表达力最强的一种。

按边是否有方向：

- **无向图**：边 `(u, v)` 与 `(v, u)` 相同；
- **有向图**：边 `<u, v>` 有方向，称为从 u 指向 v 的有向边（弧）。

按边是否有权值：

- **无权图** / **带权图**。

常用术语：

- **度**：与顶点相连的边数。有向图中分**入度**（指向该顶点的边数）和**出度**（从该顶点出发的边数）。
- **连通**：无向图中两顶点间存在路径；**连通分量**是极大连通子图。
- **DAG**：有向无环图（Directed Acyclic Graph），拓扑排序的作用对象。

### 2、图的表示

- **邻接矩阵**：`adj[i][j]` 表示顶点 i 到 j 是否有边（或权值）。判断两点是否相邻 O(1)，但空间 O(V²)，适合稠密图。
- **邻接表**：每个顶点维护一个列表，记录它指向的所有邻居。空间 O(V+E)，适合稀疏图（LeetCode 中最常用）。

```go
// 邻接表（用切片实现）
adjacency := make([][]int, n)
adjacency[u] = append(adjacency[u], v) // 添加一条 u -> v 的有向边
```

### 3、图的遍历

- **广度优先搜索 BFS**：借助队列，从起点出发逐层扩展。常用于**无权图最短路径**、层序遍历、连通分量计数。
- **深度优先搜索 DFS**：借助递归（或显式栈），沿一条路径走到底再回溯。常用于**连通性判断**、**环检测**、**拓扑排序**。

两种遍历的时间复杂度均为 O(V+E)，因为每个顶点和每条边都只访问有限次。

### 4、拓扑排序（Topological Sort）

拓扑排序针对**有向无环图（DAG）**：把所有顶点排成线性序列，使得对每条边 `<u, v>`，u 都排在 v 之前。

> **关键定理**：一个有向图存在拓扑序 **当且仅当** 它是 DAG（无环）。

因此拓扑排序天然能用来**判断有向图是否有环**。

#### 方法一：BFS（Kahn 算法）

不断「摘掉入度为 0 的叶子」：

1. 统计每个顶点的入度；
2. 入度为 0 的顶点入队；
3. 出队一个顶点加入结果，删掉它的所有出边（后继入度 -1）；后继入度变 0 时入队；
4. 队空时，若结果含全部顶点即为拓扑序，否则存在环。

特点：按层输出，结果直观；配合优先队列还能求字典序最小的拓扑序。

#### 方法二：DFS（逆后续）

DFS 中顶点在**所有后继都访问完毕**时（即「完成」时）入栈。因为后继一定先于当前顶点完成，**栈顶到栈底是逆拓扑序，翻转即得拓扑序**。

判环用三色标记：`0`=未访问，`1`=访问中（在递归栈里），`2`=已完成。遇到「访问中」的节点即发现回边，存在环。

两种方法的完整代码与运行示例见 [210 课程表 II](./No.210_课程表2.md)。
