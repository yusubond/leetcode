## 题目赏析

第一类：拓扑排序与有向图判环

这类题目针对有向图，核心是判断是否存在环，并求出（或基于）拓扑序。

- [210 课程表 II](./No.210_课程表2.md)（返回任意一种学习顺序；BFS / DFS 双解法）
- [207 课程表](./No.207_课程表.md)：判断能否完成，返回布尔值（210 的判定版本）
- [1462 课程表 IV](./No.1462_课程表4.md)：多次查询先修关系，拓扑排序 + 传递闭包

第二类：最短路径

这类题目在带权图上求单源（或多源）最短路径，核心算法是 Dijkstra（非负权）或 Bellman-Ford（可处理负权）。

- [743 网络延迟时间](./No.743_网络延迟时间.md)：单源最短路，答案取起点到各点最短距离的最大值；Dijkstra（堆 / 数组）+ Bellman-Ford 三解法
