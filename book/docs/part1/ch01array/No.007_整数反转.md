## 7 整数反转-中等

题目：

给你一个 32 位的有符号整数 `x` ，返回将 `x` 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 `[−2^31, 2^31 − 1]`，就返回 0。

**假设环境不允许存储 64 位整数（有符号或无符号）。**

> **示例 1：**
>
> ```
> 输入：x = 123
> 输出：321
> ```
>
> **示例 2：**
>
> ```
> 输入：x = -123
> 输出：-321
> ```
>
> **示例 3：**
>
> ```
> 输入：x = 120
> 输出：21
> ```
>
> **示例 4：**
>
> ```
> 输入：x = 0
> 输出：0
> ```

**关键观察：在溢出发生之前预判**

核心操作是逐位弹出和压入：`pop = x % 10; x /= 10; rev = rev*10 + pop`。问题在于最后一步 `rev*10 + pop` 可能溢出。

由于题目**禁止使用 64 位整数**，不能在溢出后再判断——必须在乘法之前预判：

- 正数溢出条件：`rev > INT_MAX/10` 或 `rev == INT_MAX/10 && pop > 7`（因为 `INT_MAX = 2147483647`，个位是 7）
- 负数溢出条件：`rev < INT_MIN/10` 或 `rev == INT_MIN/10 && pop < -8`（因为 `INT_MIN = -2147483648`，个位是 -8）

**Go 语言特例**：Go 的 `int` 在 64 位机器上是 64 位，如果直接用 `math.MaxInt32` / `math.MinInt32` 比较，实际上并没有违反"不允许存储 64 位整数"的精神——因为 Go 没有原生的 32 位整数溢出检查机制。但更严谨的写法是使用 `math.MaxInt32` 常量参与预判逻辑，而非将结果存入 `int64` 再比较。

**解法 1：逐位反转 + 溢出预判**

```go
// date 2026/07/08
func reverse(x int) int {
    const (
        maxInt32 = 1<<31 - 1 // 2147483647
        minInt32 = -1 << 31   // -2147483648
    )
    rev := 0
    for x != 0 {
        pop := x % 10
        x /= 10
        // 正溢出预判
        if rev > maxInt32/10 || (rev == maxInt32/10 && pop > 7) {
            return 0
        }
        // 负溢出预判
        if rev < minInt32/10 || (rev == minInt32/10 && pop < -8) {
            return 0
        }
        rev = rev*10 + pop
    }
    return rev
}
```

**解法 1 变体：统一溢出判断**

利用 Go 中 `int` 默认为 64 位的特性，可以简化溢出判断——先算出结果，再检查是否超出 32 位范围。这种方式代码更短，虽然"技术上"用到了 64 位空间来存储中间结果，但思路更清晰，在面试中也常被接受。

```go
// date 2026/07/08
func reverse(x int) int {
    rev := 0
    for x != 0 {
        rev = rev*10 + x%10
        x /= 10
    }
    if rev > 1<<31-1 || rev < -1<<31 {
        return 0
    }
    return rev
}
```

> **注意**：此写法依赖 Go 的 `int` 为 64 位（在 64 位机器上），如果语言或环境使用 32 位 `int`（如 Java、C），则 `rev` 自身会在赋值时溢出，这种简化写法无效。解法 1 的预判逻辑才是跨语言的通用解法。

**复杂度**

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 逐位反转 + 溢出预判 | O(log₁₀ n) | O(1) | 循环次数 = 数字位数，最多 10 次（32 位整数最多 10 位） |
| 变体（Go 简化版） | O(log₁₀ n) | O(1) | 依赖 64 位 int，不适用于 32 位 int 语言 |
