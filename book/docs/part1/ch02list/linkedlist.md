# 链表LinkedList

## 1.单链表

单链表节点的定义通常是下面这个结构：

```go
// Definition for singly-linked list.
type ListNode struct {
  Val int
  Next *ListNode
}
```

`Val`表示节点的值，也可根据实际需要换成其他类型或结构。

`Next`表示该节点的下一个节点。



## 2.链表的技巧

### 2.1 快慢指针

在数组章节我们学习过双指针技巧，一种是两个指针从前后一起遍历，向中间逼近，即对撞指针；也有读写指针维护不同的数据元素。

而在链表的运用中，由于单链表只能单向遍历，可以通过调整两个指针的遍历速度完成某种特定任务，即「快慢指针」技巧。



快慢指针有几个常见的用法：

**用法1：找单链表的中点**

快指针走2步，慢指针走1步，当快指针走完的时候，慢指针刚好在一半的位置。

这类题目有：

- [876 链表的中间节点](./No.876_链表的中间节点.md)
- [143 重排链表](./No.143_重排链表.md)
- [234 回文链表](./No.234_回文链表.md)



**用法2：判断是否相交，或者是否有环**

如果存在相交或者有环，那么两个指针一定会走到一起。

这类题目有：

- [141 环形链表](./No.141_环形链表.md)
- [142 环形链表2 求环入口](./No.142_环形链表2_求环入口.md)
- [160 相交链表，求交点](./No.160_相交链表.md)



**用法3：寻找倒数第 N 个节点**

快指针先行 N 步，慢指针再从头节点开始走，那么当快指针走到结束的时候，慢指针刚好走到第 N 个节点。

这类题目有：

- [19 删除链表中的倒数第N个节点](./No.019_删除链表中的倒数第N个节点.md)



**用法4：快慢指针形成一个窗口**

对于要求链表中节点连续，并满足一定条件的题目，可用 start/end 指针形成的窗口进行判断。

这类题目有：

- [82 删除链表中的重复元素2](./No.082_删除排序链表中的重复元素2.md)
- [817 链表的组件，类似求最长连续子序列和](./No.817_链表组件.md)



### 2.2 哨兵结点

哑结点，也称为哨兵结点。常见的场景有：

**用法1：保存结果集**

遍历原链表，将最终的结果保存在哑结点起始的链表中。

这类题目有：

- [002 两数求和](./No.002_两数求和.md)
- [021 合并两个有序链表](./No.021_合并两个有序链表.md)
