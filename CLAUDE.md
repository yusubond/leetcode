## Project Overview

数据结构与算法（Data Structures & Algorithms）— personal learning repository. Contains a Hugo-powered book documenting data structures and algorithms with LeetCode problem solutions, plus Go implementations of common data structures.

## Repository Structure

```
book/          # Markdown source for the algorithm book (Hugo content)
  _index.md    #   Book preface/landing page
  docs/        #   Chapters: part1 (基础), part2 (进阶), part3 (高级)
  menu/        #   Sidebar menu definition
  assets/      #   Images (PNG/SVG) referenced by docs
website/       # Hugo site — builds and serves the book at subond.com/leetbook
  make.go      #   Script: copies book/ docs → website/content/, fixing asset paths
  Makefile     #   `make all` runs make.go; `make s` runs hugo server
  hugo.toml    #   Hugo config (theme: hugo-book, baseURL: subond.com/leetbook)
  content/     #   Generated by make.go — not committed
  static/      #   Generated by make.go — not committed
template/      # Go implementations of data structures (package template)
  *.go         #   linkedlist, double_linkedlist, stack, lru/lfu cache,
               #   sort, trie, segment_tree, binary_indexed_tree, union_find
  *_test.go    #   Corresponding test files
web2/          # Alternate/simpler Hugo site (similar pattern to website/)
drawio/        # Draw.io diagram source files (*.drawio)
```

## Common Commands

### Book Website (website/)

```bash
cd website
make all        # Copy book docs → Hugo content/ (runs make.go)
make s          # Build + start Hugo dev server with drafts
```

The `make.go` script walks `../book/` and copies Markdown files to `content/`, replacing `./assets` paths with the correct Hugo static asset paths. Images go to `static/img/`.

### Go Data Structures (template/)

```bash
cd template
go test ./...           # Run all tests
go test -run TestName   # Run a specific test
```

There is no build step — template is a library package, not a binary.

## Key Conventions

- **LeetCode problem files** are named `No.XXX_题目名.md` (e.g., `No.001_两数之和.md`)
- **Rating system**: problems rated ⭐ 1–5 for design quality
- **Book chapters** follow `partN/chXXtopic/` structure (e.g., `part1/ch01array/`)
- **Assets** within book chapters live in a local `assets/` subdirectory; make.go flattens them into the Hugo static directory
- **`website/content/` and `website/static/`** are .gitignored — they're generated artifacts
